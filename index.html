About the Game

Your Fly Zone is an intense defense-themed game where your primary mission is to safeguard the zone from incoming aerial threats. Upgrade your systems, manage your resources efficiently, and keep the airspace secure. This custom fork introduces enhanced UI mechanics, optimized performance, and refined gameplay features.

What's Changed in v0.1 (Fork)
  • Added interactive button hover animations on the main menu.
  • Optimized core game functions and underlying logic for improved performance.
  • Redesigned user interface (UI) for a cleaner and more modern look.
  • Smoother animations and refined overall user experience.
